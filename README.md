# Infrathon website

Static site for **Infrathon: Can Frontier Models Solve Long-Horizon AI Infrastructure Tasks?**
It is plain HTML, CSS and JavaScript with no build framework. Every chart is drawn in the browser from one generated data file.

```
site/                    what gets published
  index.html
  assets/css/site.css    design tokens and layout
  assets/js/app.js       all charts and interactions
  assets/img/            figures cropped from the paper (Fig. 3, 4, 5)
  data/infrathon.js      GENERATED by scripts/build_data.py
data/
  tasks.json             task registry: names, levels, metrics, flags, ranking eligibility
  tokens.json            token / turn summary from the trajectory analysis
  raw/runs.json          per-run scores and submissions, extracted from the dashboard export
scripts/
  extract_dashboard.py   dashboard zip -> data/raw/runs.json
  build_data.py          data/* -> site/data/infrathon.js (rank scores, bootstrap, etc.)
  check_site.py          local references, anchors, no leaked local paths
tests/test_data.py       asserts the site reproduces paper Figure 3 and Table 13
```

## Updating results

```bash
python3 scripts/extract_dashboard.py /path/to/dashboard-tasks-html-YYYYMMDD-HHMMSS.zip
python3 scripts/build_data.py
python3 -m unittest discover -s tests -v
```

`extract_dashboard.py` keeps the latest cohort folder of each task (by the trailing date) and applies the paper's run selection.
The selection drops Gemini, the voided LLaDA DeepSeek attempt, and Sol's local Mamba-2 rerun.
Flags, exclusions and task text live in `data/tasks.json`.
If a new export changes the paper's numbers, update the expected values in `tests/test_data.py` along with the paper.

Preview locally with `python3 -m http.server -d site 8000`.

## Ranking

The rank score follows the paper's Eq. 6. On each of the 17 tasks with comparable finals for all six configurations, rank the configurations by final score; exact ties share the average rank. Then:

RankScore_m(G) = 100 / (|G| (K-1)) · Σ_τ (K − ρ_τ,m), with K = 6

The leaderboard recomputes this in the browser for any task subset, and for either endpoint (final artifact or best during run).
The 95% intervals and P(#1) come from bootstrap resampling of tasks.

## Deployment

`.github/workflows/pages.yml` runs on every push and pull request.
It rebuilds the data bundle, fails if the committed bundle is stale, runs the tests and site checks, and then deploys `site/` to GitHub Pages from `main`.

One-time repository settings:

1. The repository must be public, or the account needs a plan that allows Pages on private repositories.
2. Under Settings → Pages → Build and deployment, set Source to **GitHub Actions**.
