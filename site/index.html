Why AI infrastructure

Models improving the stack that builds models

Faster kernels, cheaper training steps and better serving schedulers are how compute turns into better models. If agents can do this engineering reliably, each model generation can speed up the training and serving of the next. That is the loop behind recursive self-improvement.

Infrathon measures one step of that loop on real workloads: a working system or an empty file, a fixed wall-clock budget, real profilers, and a judge the agent cannot inspect. The agent has to make the system faster without changing what it computes.
