Agent Behavior Analysis

Can frontier models solve real-world long-horizon AI infra tasks?

Q1 · Task requirementsQ2 · Experimental validationQ3 · Continued improvement
Q1

Do Agents Follow Task Requirements?

Not consistently. Local checks can pass even when an optimization changes the required computation.

Q2

Do Agents Correctly Test Their Own Optimizations?

Not consistently. Agents can measure the wrong code path or choose an optimization using an unrepresentative workload.

Q3

Do Agents Keep Improving over Long Horizons?

Often, but unevenly. Further code changes can improve scores after a completion claim; repeated submissions can also increase without new implementation work.
