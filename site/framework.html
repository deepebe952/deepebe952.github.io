A common task specification

τ = (W, P, E, R, T)

WWorkspace
The starting code or interface to implement, together with the files and behavior the agent is allowed to change.
PPublic tests
Visible test cases and a public runner for local correctness checks and profiling.
EPrivate tests
Hidden cases, task-specific checks, the scoring objective and its direction, and permitted feedback. Private cases and scoring code remain inaccessible to the agent.
RResources
The hardware allocation and software runtime used for development and evaluation.
TTime budget
Wall-clock time for agent interaction, tool execution, and feedback waits. Operators receive 12 h; modules and systems, 24 h. T = ∞ permits execution without a preset deadline.

Task Execution

Work develops candidates, the Controller checks submissions, and the Judge evaluates accepted snapshots.

  1. Work environment

    The model and its tools act together: inspect files, edit code, profile, run public tests, save candidates, and request private evaluation.

    Actions, tool outputs, local diagnostics, and permitted feedback form the agent-visible history.

  2. Controller

    The trusted Controller snapshots allowed files and manages submission limits and cooldowns. An agent checks the snapshot against task instructions and editable scope; the Controller verifies the cited evidence before rejecting it.

    Accepted snapshots go to the Judge. An integrity rejection returns a reason and no performance score. Explicit saves and accepted submissions are recorded with timestamps.

  3. Judge environment

    Private tests run on accepted snapshots using the task’s allocated hardware and runtime. Validation can require exact outputs, numerical tolerances, or downstream quality thresholds.

    Performance follows each task’s objective, such as latency or throughput. Memory is measured where constrained.

Continued execution

A stop hook prompts further work when the agent attempts to finish. Session recovery resumes eligible exits in the same session and workspace.

Both mechanisms use the original run deadline.
